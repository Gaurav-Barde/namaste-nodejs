• NodeJS is a JavaScript runtime built on Chrome's V8 JS engine.

• NodeJS is a cross platform, open source JavaScript runtime environment that can run on Windows, Linux, Unix, macOS and more.

• NodeJS runs on the V8 JS engine and executes JS code outside a web browser

• It is maintained by Open JS foundation.

• NodeJS has an event-driven architecture capable of asynchronous I/O.

• Today NodeJS is successful because it has an event-driven architecture
• Asynchronous I/O also known as non-blocking I/O
• History of NodeJS
• First version of NodeJS is released in 2009 by a developer Ryan Dahl
• To run JavaScript you always need a JS engine. You cannot run any code without it
• When Ryan Dahl developed NodeJS first time, he used Spider Monkey JS engine
• You can find Spider Monkey JS engine in Mozilla firefox browser
• Every browser has its own JS engine
• After 2 days of release NodeJS Ryan started using Google's V8 engine
• Today also tge latest version of NodeJS is using V8 engine behind the scenes
• At that time a company named Joyent was also working on an internal project where they were trying to run JS on the server. And they were really fascinated by idea of Ryan Dahl. so afterwards Ryan worked under them and they funded the project. Joyent played very big role in NodeJS development
• Initially the few project built using NodeJS were built & used inside the Joyent Company.
• Earlier name of NodeJS was WebJS because he wanted to create web servers. But later he realized the potential of WebJS & changed its name to NodeJS
• NodeJS was created because there was a HTTP server called Apache & it was a blocking server. Now Ryan wanted to create a non-blocking server
• In 2010 NPM was created by a developer from Joyent.
• NPM is a package manager for Node
• NPM is basically a central registry where you can add different packages for different development needs
• Development of NPM was a significant achievement for Node
• In 2011 NodeJS got the Windows support, Initially it was supported for only Mac OS & Linux
• In 2012 Ryan left the NodeJS project and now it is led by Isaac the creator of NPM
• In 2014 a developer named Fedor forked NodeJS repo & named it as io.js
• In Sep. 2015 io.js and NodeJS are merged & a committee being formed for maintaining NodeJS known as NodeJS foundation
• In 2019 JS foundation & NodeJS foundations are merged as OpenJS foundation & it took the control of NodeJS & responsibility for active development of NodeJS
